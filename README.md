# Таблички на двері

Редактор табличок на двері кабінетів. Одна сторінка, без збірки й залежностей — відкривається у браузері.

**Відкрити:** https://hrechukhin.github.io/tablychky/

## Що вміє

- Список кабінетів: номер, назва, категорія. Рядки додаються й видаляються.
- Кольори категорій (гуманітарні, точні, природничі, суспільні, початкова школа, адміністрація).
- Назва закладу в підписі та власна емблема з файлу, з регулюванням розміру.
- Ширина кольорового блоку таблички.
- Дві розкладки для друку: одна табличка на сторінку 297 × 105 мм або дві на аркуш A4 з лінією різу.
- Стан зберігається в `localStorage` браузера.

## Друк

Кнопка «Друкувати / зберегти PDF» відкриває вікно друку. У ньому:

- призначення — «Зберегти як PDF»;
- поля — «Немає»;
- масштаб — 100 %;
- увімкнути друк фонової графіки.

## Локально

Достатньо відкрити `index.html` у браузері.
